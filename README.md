# 章章 CoachNote

健身教练自用 PWA 排课工具。**纯前端**：Vue3 + Vite + Element Plus + dexie.js（IndexedDB），
无后端、无服务器，数据全部保存在手机浏览器本地。

- 客户信息管理（姓名 / 电话 / 性别 / 备注 / 剩余课时）
- 排课日历（月视图 / 日视图 / 列表视图），支持新增、编辑、删除、时间冲突校验；
  上课时间固定限定 09:00 - 22:00，排课状态仅「待上课 / 已完成」
- 课时业务逻辑：标记「已完成」自动扣减 1 节，剩余 0 节禁止扣减；日视图支持「快捷下课」一键完成
- 首页统计面板：今日排课重点展示（不可点击）；已上课 / 待上课跳转课程记录页（日期 + 课程简述）；客户总数跳转客户管理页
- 课程提醒：PWA 浏览器通知（固定提前 10 分钟 / 5 分钟提醒）+ 导出 ICS 导入 iPhone 系统日历兜底
- 数据规则：每次打开自动删除一个自然月之前的历史排课，一个月内数据全部保留；「取消」排课状态已彻底移除（含遗留数据清理）
- 数据工具：一键导出 / 导入 JSON 备份

## 环境要求

- Node.js ≥ 18（推荐 20/22）
- npm ≥ 9

## 一、本地启动

```bash
# 1. 安装依赖（首次）
npm install

# 2. 启动开发服务器
npm run dev
```

浏览器访问终端输出的地址（默认 http://localhost:5173）。
开发模式下 PWA Service Worker 不启用，PWA 效果请用「构建 + 预览」或部署后验证。

## 二、打包构建

```bash
npm run build
```

产物输出到 `dist/` 目录（含 `manifest.webmanifest`、`sw.js` 及图标，可直接静态托管）。

本地预览构建产物：

```bash
npm run preview
```

## 三、Cloudflare Pages 部署（上传 dist 文件夹方式）

1. 本地执行 `npm run build`，得到 `dist/` 目录；
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) → 左侧菜单 **Workers & Pages** → **Create** → **Pages**；
3. 选择 **Upload assets**（上传静态资源）方式；
4. 输入项目名称（如 `coachnote`），把 `dist/` 文件夹**整个拖入**上传区；
5. 点击 **Deploy site**，等待部署完成；
6. 部署完成后会得到类似 `https://coachnote.pages.dev` 的地址。

> 提示：Cloudflare Pages 会自动托管 `sw.js` 与 `manifest.webmanifest`，无需额外配置；
> 本项目使用 hash 路由，刷新页面也不会 404。

## 四、iPhone 添加主屏幕（安装 PWA）

1. 使用 **Safari 浏览器**打开部署地址（或本地局域网预览地址）；
2. 点击底部工具栏的 **分享按钮**（方框+箭头）；
3. 向下滑动，点击 **添加到主屏幕**；
4. 确认名称「课记」，点击右上角 **添加**；
5. 主屏幕出现「课记」图标，点击打开即为**全屏独立应用**（无地址栏、无 Safari 工具栏）。

> 注意：PWA 必须通过 HTTPS 访问（Cloudflare Pages 自带 HTTPS）；本地调试可用
> `npm run preview` + 手机与电脑同一局域网访问，但通知功能仍需 HTTPS + 已安装状态。

## 五、通知权限开启说明

1. 打开「课记」→ 底部 **设置** → **课程提醒**；
2. 点击 **开启通知授权**，在系统弹窗中选择 **允许**；
3. 打开 **课前提醒** 开关，并选择提前提醒时间（15 / 30 / 60 / 120 分钟）；
4. 可点击 **发送测试通知** 验证。

iPhone 注意事项：

- iOS 网页通知仅在 **iOS 16.4 及以上**、且应用**已添加到主屏幕**（独立模式）时可用；
- 通知在应用**打开/前台运行**时触发（后台无法定时执行）；
- 若误点「不允许」，请到 iPhone **设置 → Safari → 通知**（或该站点设置）中重新开启。

## 六、导出 ICS 导入 iPhone 系统日历（兜底提醒）

应用内两处可导出 ICS：

- 排课弹窗（新建 / 编辑排课时）右下角 **导出 ICS** → 导出当前这一节；
- 设置页 → 数据管理 → **导出全部排课为 ICS** → 导出全部未取消排课。

导入 iPhone 系统日历步骤：

1. 导出后浏览器会下载 `.ics` 文件（Safari 中点击下载）；
2. 打开 **文件 App** → 找到下载的 `coachnote-xxx.ics` 文件；
3. 点击该文件 → 系统弹出「日历」预览；
4. 点击右上角 **添加全部**（或选择「添加到日历」）；
5. 打开 **日历 App** 即可看到对应日程，到点自动提醒，完全离线可用。

> 建议：网页通知 + 系统日历双保险。排课完成后，如需取消日历提醒，
> 在系统日历中删除对应日程即可。

## 七、数据说明与备份

- 所有数据存于浏览器 **IndexedDB**（数据库名 `coachnote`），不会上传任何服务器；
- **自动清理**：每次打开应用自动删除一个自然月之前的历史排课，一个月内数据全部保留（客户资料不受影响）；
- **上课时间**：整体固定限定 09:00 - 22:00，排课不超出该区间；排课状态仅「待上课 / 已完成」（取消状态已移除）；
- **快捷下课**：日视图中每节待上课排课右侧有「✓」按钮，点击直接标记为已完成并自动扣减 1 节课时，无需打开详情；
- **课前提醒**：固定提前 10 分钟、5 分钟各提醒一次，设置页开关即可；
- **备份**：设置页 → 数据管理 → **一键导出全部数据（JSON）**，建议定期导出保存；
- **恢复**：设置页 → 数据管理 → **一键导入数据（JSON）**，导入会覆盖当前全部数据（有确认提示）；
- 换手机 / 清浏览器缓存前，请先导出 JSON 备份。

## 八、项目结构

```
coach-note/
├── index.html                  # 入口 HTML（含 iOS PWA meta）
├── vite.config.js              # Vite + vite-plugin-pwa 配置
├── public/
│   ├── favicon.svg
│   └── icons/                  # PWA 图标（192/512/maskable/apple-touch）
├── scripts/
│   └── gen-icons.ps1           # 图标生成脚本（可选，重新生成图标用）
└── src/
    ├── main.js                 # 应用入口
    ├── App.vue                 # 应用外壳（数据初始化、自然月清理、提醒调度）
    ├── router/index.js         # 路由（hash 模式）
    ├── db/index.js             # dexie.js 数据库定义 + 数据清理
    ├── utils/                  # 时间、ICS 等工具函数
    ├── composables/            # 客户/排课/设置/空闲时段/通知/提醒/数据工具
    ├── components/             # 日历三视图、表单弹窗、底部导航
    └── views/                  # 首页/排课/客户/课程记录/汇总统计/设置
```
